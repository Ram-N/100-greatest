Below is the simplest, lowest-risk way to get a manuscript into **KDP** if this is your first time.

---

## What KDP expects (conceptually)

Think of KDP as doing three things:

1. Ingesting your manuscript
2. Converting it to Kindle formats
3. Letting you preview and fix issues before publishing

Your job is to give it a **clean, boring, well-structured document**.

---

## Step 1: Prepare the Word manuscript (most important)

Create **one single Word file**.

### Basic structure (recommended order)

* Title page
* Copyright page
* (Optional) Dedication / Epigraph
* Table of Contents (TOC)
* Main chapters
* (Optional) Notes / References / Acknowledgments

Each of these should start on a **new page**.

Use:

* Page breaks (Insert → Page Break)
* Not multiple blank lines

---

### Headings (critical)

Use Word styles, not manual formatting.

* Book title: **Normal text, centered**
* Chapter titles: **Heading 1**
* Subsections: **Heading 2**

This allows KDP to:

* Auto-generate a clickable Kindle TOC
* Build Kindle navigation correctly

Do not:

* Bold + enlarge text instead of using styles
* Manually number chapters in the TOC

---

### Paragraph formatting

* Font: Times New Roman, Garamond, or similar
* Font size: 11 or 12
* Line spacing: 1.15 or 1.2 (not double-spaced)
* First-line indent: yes
* No extra blank lines between paragraphs

Avoid:

* Tabs for indentation
* Manual spacing with spaces

---

### Images (if any)

* Insert images inline (not floating)
* Center them
* Add simple captions if needed
* Make sure you own the rights

If unsure, skip images for this first upload.

---

## Step 2: Create or let KDP create the TOC

Two safe options:

### Option A (recommended)

* Use Word headings
* Let KDP auto-generate the TOC

### Option B

* Create a simple TOC in Word
* Use Word's automatic TOC feature

Do not:

* Type a manual TOC by hand

---

## Step 3: Final checks before upload

In Word:

* scan headings
* Check for extra blank pages
* Check chapter breaks
* Save as **.docx**

Filename example:

```
book-title-YYYY-MM-DD-HH-MM.docx
```

---


---

## Key advice (learned the hard way)

* Simple beats fancy
* Word styles beat manual formatting
